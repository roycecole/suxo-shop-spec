# 00 - 專案總覽 (Overview)

來源文件：`docs/00-overview.md`

## 這份文件負責回答
整個文件集的入口：說明 ShyeCMS 與電商平台是兩個獨立系統的緣由、彙整所有鎖定決策，並提供 §6 完整文件索引。

## 涵蓋章節
- 1. 本文件集的緣起
- 2. 原始需求與可行性分析結論（含 v0.2 修正）
- 3. 架構決策（v0.2 現況，取代 v0.1 決策 C、D）
- 4. 名詞定義
- 5. 角色定義
- 6. 文件索引
- 7. ShyeCMS 對系統商既有維運缺口的回應
- 8. 前身規格涵蓋、本文件集未涵蓋的範圍

## 使用注意
- §8 記錄了前身規格（原 docs/00–16）已被刪除、目前刻意未涵蓋的範圍——回答「這個系統以前是不是有規劃過 X」之類問題前，先查這裡再回答，不要假設內容還存在。

## 修改這份文件時
- 依 `spec-add-changelog-entry` Skill 的步驟新增異動紀錄（版號/日期/作者/說明），不要靜默修改內容。
- 若此文件的異動影響到其他文件的索引或交叉引用，依 `spec-check-cross-references` Skill 檢查並同步。
